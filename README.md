# FridgeFlow - המהפכה הדיגיטלית בעולם הפתקיות

## מבוא
FridgeFlow הוא יישום מתקדם של לוח פתקיות דיגיטלי עם פונקציונליות משופרת, המאפשר למשתמשים:

- יצירה וניהול של פתקים דיגיטליים
- ציור חופשי על גבי הלוח
- הוספת אימוג'ים ותמונות
- שיתוף פתקים עם חברים
- אחסון והסנכרון באמצעות Supabase

## התקנה

```bash
npm install
```

## הרצה בסביבת פיתוח

```bash
npm run dev
```

## מבנה בסיס הנתונים

הפרויקט משתמש ב-Supabase כשירות Backend. הקובץ `setup_table.sql` מכיל את ההגדרות הדרושות ליצירת טבלת הנתונים.

## פיתוח עתידי

התכונות הבאות מתוכננות לפיתוח בגרסאות הבאות:
- יכולת דירוג פתקים ומיון לפי חשיבות
- הוספת תזכורות ותאריכי יעד
- אפשרויות עיצוב מורחבות

## סיכום

פרויקט FridgeFlow מספק פתרון חדשני לניהול פתקים דיגיטליים עם ממשק משתמש נוח ואפשרויות מתקדמות.
